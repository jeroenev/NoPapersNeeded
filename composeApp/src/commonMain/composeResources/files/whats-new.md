# What's new in 0.1.0

## Report a problem

- Settings > About now has **Report a problem**. It writes a diagnostics file with the app version, platform, library counts and recent log, with document names, paths, addresses and keys removed.
- It opens a prefilled GitHub issue and shows the file's path, so you can attach it in one step.
- Nothing is uploaded automatically. You choose what to share.

## Better crash reports

- Warnings and errors are now kept in a size-capped log file on both desktop and Android, so a crash leaves something to read.
- An uncaught crash is written to that log before the app closes.

## Release notes in the app

- **What's new** is available from Settings > About, and appears once after the app updates.
